# 01 — Продукт

## Видение
Расширение для Chrome, которое позволяет управлять списками Shikimori, не открывая сайт: нашёл тайтл — в два клика добавил в «Запланировано», отметил серию, поставил оценку. Ключевое качество — скорость: popup открывается мгновенно, поиск отвечает быстрее, чем успела бы загрузиться страница сайта.

## Целевой пользователь
Один пользователь — владелец проекта, авторизуется под своим аккаунтом Shikimori. Это упрощает решения: не нужны онбординг, аналитика, миграции настроек, мультиязычность.

## Не-цели (осознанно НЕ делаем)
- Комментарии, форум, клубы, личные сообщения
- Просмотр видео / чтение манги
- Полный клон сайта: детальные страницы с описаниями, скриншотами, персонажами (максимум — компактная карточка)
- Публикация в Chrome Web Store (пока)
- Поддержка Firefox/Safari (архитектура не должна мешать добавить позже, но время на это сейчас не тратим)

## Функциональность по фазам
| Фаза | Что входит |
|---|---|
| 1 | OAuth2-вход, профиль (ник, аватар), выход |
| 2 | Поиск аниме, статус «в моём списке», добавление / смена статуса / удаление |
| 3 | Мои списки по статусам, оценка 1–10, «+1 эпизод», прогресс |
| 4 | Манга и ранобэ: поиск + списки (главы/тома вместо эпизодов) |
| 5 | Контекстное меню: поиск выделенного текста |
| 6 | Полировка: перфоманс-аудит, иконки, README, упаковка |

## User stories и критерии приёмки

### US-1. Авторизация
Как пользователь, я хочу войти через свой аккаунт Shikimori, чтобы расширение управляло моими списками.
- [ ] Кнопка «Войти через Shikimori» открывает окно авторизации сайта
- [ ] После подтверждения popup показывает мой ник и аватар (данные whoami)
- [ ] Сессия переживает перезапуск браузера (токены в storage, авто-refresh)
- [ ] Кнопка «Выйти» очищает токены и возвращает экран входа
- [ ] Если refresh не удался (токен отозван) — расширение показывает экран входа и не зацикливается

### US-2. Поиск аниме
- [ ] Поле поиска с debounce ~300 мс, результаты ≤ 10 шт.
- [ ] Карточка: постер, русское и оригинальное название, тип (TV/фильм/OVA…), год, оценка сайта, статус (анонс/онгоинг/вышло)
- [ ] Если тайтл уже в моём списке — виден бейдж моего статуса
- [ ] Состояния: пустой запрос — подсказка; ничего не найдено — явное сообщение; ошибка сети — кнопка «Повторить»

### US-3. Добавление в список
- [ ] Карточка не из списка: primary-кнопка «+ Запланировано» (1 клик) и меню выбора другого статуса
- [ ] Карточка из списка: бейдж текущего статуса, по клику — меню «сменить статус / удалить»
- [ ] UI обновляется оптимистично; при ошибке — откат + тост с текстом ошибки
- [ ] Статусы: запланировано, смотрю, пересматриваю, просмотрено, отложено, брошено

### US-4. Мои списки
- [ ] Вкладка «Мои списки»: фильтр по статусу и типу (аниме/манга/ранобэ)
- [ ] Строка: постер, название, прогресс `X / N эп.` (или глав), моя оценка
- [ ] Подгрузка порциями (limit ~30, кнопка «Ещё»)

### US-5. Оценка
- [ ] Для тайтла из списка можно выставить/изменить оценку 1–10, 0 = снять оценку
- [ ] Оценка сохраняется через API и видна на сайте

### US-6. +1 эпизод
- [ ] Кнопка «+1» у тайтлов в статусах «смотрю» / «пересматриваю»
- [ ] Если после инкремента прогресс == всего эпизодов — inline-предложение «Перевести в „Просмотрено“?» (НЕ автоматически)
- [ ] Для манги/ранобэ инкремент увеличивает главы

### US-7. Манга и ранобэ
- [ ] Переключатель типа поиска: Аниме / Манга / Ранобэ (ранобэ = manga с kind light_novel/novel)
- [ ] Карточки показывают тома/главы вместо эпизодов
- [ ] Списки работают с target_type=Manga

### US-8. Контекстное меню
- [ ] Пункт «Найти „%s“ на Shikimori» при выделении текста на любой странице
- [ ] Открывает страницу поиска расширения (entrypoints/search) в новой вкладке с уже выполненным запросом
- [ ] Работает без открытого popup

## Метрики качества
- Открытие popup → интерактивность: < 150 мс (первый рендер из кэша)
- Ответ поиска после debounce: p50 < 500 мс при нормальной сети
- Ноль превышений лимитов API в обычных сценариях (ни одного 429 в smoke-тестах)

### Дополнение фазы 3 — по итогам smoke (решение владельца 2026-07-23) — закрыто 2026-07-24 (smoke пройден владельцем)
- [x] Смена статуса (и удаление) из строки «Моих списков»: StatusMenu в RateRow, как на карточке поиска; строка, чей новый статус не соответствует текущему фильтру, после подтверждения сервером уходит из списка
- [x] Фикс: изменение статуса на стороне сайта не подтягивается в открытый список (пример: досмотр последней серии на сайте авто-переводит тайтл в «Просмотрено», у нас строка остаётся в «Смотрю» до смены фильтра) — список перезапрашивается при каждой активации вкладки, а не только при смене фильтра (было: `activate()` рефрешил один раз за жизнь popup). Тот же инвариант применён к increment: серверный авто-перевод статуса на последней серии убирает строку из отфильтрованного списка

**DoD дополнения (ручной smoke владельца):** смена статуса из строки видна на сайте; удаление из строки удаляет user_rate на сайте; строка уходит из отфильтрованного списка после подтверждения; после изменения статуса на стороне сайта переоткрытие popup / реактивация вкладки показывает актуальный список без манипуляций с фильтром.

- [x] **Изменение сценария по решению владельца 2026-07-27:** клик по пункту меню открывает **popup** (`action.openPopup()`, Chrome 127+), запрос передаётся через одноразовый `session.pendingSearch`; полноэкранная страница осталась запасным путём на случай, когда popup открыть не удалось

**Код закрыт 2026-07-27** (конвейер Ф5-1…Ф5-10, ревью «можно коммитить» без блокеров, 341 тест). **Ждёт ручной smoke владельца.**

**DoD:** выделил название на любом сайте → пункт меню → открылся popup с готовыми результатами; работает при закрытом popup.
**Smoke:** выделить название на произвольном сайте при полностью закрытом popup → в меню виден текст выделения → открывается popup, вкладка «Поиск» активна, результаты на месте (кириллица и латиница); новая вкладка при этом НЕ открывается; выделение в 300+ символов не ломает поиск; предыдущий тип поиска («Манга»/«Ранобэ») не мешает — запрос уходит по аниме; добавление в список и смена статуса из popup видны на сайте; «холодный» service worker (подождать ~30 с простоя или terminate в `chrome://serviceworker-internals`) — пункт меню по-прежнему работает; перезапуск Chrome → пункт на месте без переустановки; открыть popup вручную после этого — прошлый запрос из меню не повторяется; выйти из аккаунта → поиск из меню показывает экран входа, а после входа открытый вручную popup сам доигрывает тот же запрос.
**Отложено (follow-up, не блокеры — из ревью Ф5-9):** список результатов и обвязка мутаций продублированы между `popup/App.vue` и `search/SearchPage.vue` (просится общий `SearchResults.vue` + composable); страница переопределяет приватные BEM-классы общих компонентов через `:deep()` — при выносе общего layout заменить на проп-вариант (`popup`/`page`) или CSS-переменные.
